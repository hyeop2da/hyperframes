# 먼작귀 데스크톱 응원 위젯

치이카와·하치와레·우사기가 화면 아래쪽에 함께 서서, **머리 위로 포스트잇(할 일 메모)을 들고 다니며** 내가 일하는 동안 같이 집중해 줍니다.

## 1. 설치와 실행

Python 3.9 이상이 필요합니다. 외부 라이브러리는 PyQt5 하나뿐입니다.

```bash
cd chiikawa-desk
pip install -r requirements.txt
python chiikawa_desk.py
```

- `frames/poses/`(잘라 둔 12포즈)가 함께 들어 있어 바로 실행됩니다.
- 설정과 메모는 `~/.chiikawa_desk/`(`config.json`, `notes.json`)에 저장됩니다. 내 PC 밖으로 나가지 않습니다.
- 옵션: `--reset`(위치·크기·타이머 초기화, 메모는 유지) · `--debug`(상태 전환 로그) · `--diagnose-input`(작업 감지 확인)

## 2. 조작

| 조작                  | 동작                                                                             |
| --------------------- | -------------------------------------------------------------------------------- |
| 캐릭터 좌클릭         | 타이머 카드 열기/닫기                                                            |
| 캐릭터 좌클릭 드래그  | 이동 (머리 위 포스트잇도 함께 따라옴)                                            |
| 마우스 휠 / `Ctrl`+휠 | 그 캐릭터 크기 / **모든 캐릭터** 크기 (0.08~3배, 가장 작게 약 20px)              |
| 캐릭터 우클릭         | 타이머 카드 · 포스트잇 펼치기/접기 · 응원 · 크기 · 투명도 · 설정 · 숨기기 · 종료 |
| 트레이 아이콘         | 보이기/숨기기 · 설정 · 오늘은 퇴근 알림 끄기 · 종료                              |

캐릭터는 기본 85% 반투명이고, 마우스를 올리면 선명해집니다. 말풍선은 없습니다. 글자는 포스트잇과 타이머 카드에만 나옵니다.

## 3. 머리 위 포스트잇

폴드 메모 영상의 포스트잇을 캐릭터가 두 손으로 들고 다닙니다. 캐릭터마다 한 장입니다.

- **접힌 쪽지**: 머리 위의 작은 쪽지(제목 + 완료/전체). 쪽지를 누르면 **펼쳐집니다**.
- **펼친 노트**: 제목과 본문을 씁니다. 머리 위 `–` 버튼이나 `Esc`로 **다시 접습니다**. 색 점을 누르면 6색(노랑·분홍·하늘·연두·보라·주황), `×`를 두 번 누르면 내용을 지웁니다.
- **체크리스트**: `Ctrl+Enter`로 체크 항목을 만들고, 항목 앞 ☐ 를 누르면 완료(취소선)가 됩니다. 완료하면 그 캐릭터가 기뻐합니다.
- 첫 줄이 제목입니다. 입력하는 대로 자동 저장됩니다("저장됨").
- 마감·퇴근 알림은 쪽지가 흔들리고 테두리가 깜빡이는 것으로 알려 줍니다.

> 메모는 PC에 **평문**으로 저장됩니다. 비공개 문서명이나 개인정보는 적지 않는 것을 권합니다.

## 4. 내 작업에 반응하기 (다른 프로그램에서 작업할 때도)

메모장·문서·메일·브라우저 어디서 작업해도 캐릭터가 함께 움직입니다. 집중 타이머를 켜지 않아도 동작합니다.

| 단계 | 조건(기본값)                         | 반응                                                               |
| ---- | ------------------------------------ | ------------------------------------------------------------------ |
| 시작 | 최근 10초 중 활동이 이어짐(3초 이상) | 대표 캐릭터가 **집중 포즈**로 바뀜                                 |
| 함께 | 약 30초 동안 활동이 이어짐           | 나머지 캐릭터가 1.5~6초 시차를 두고 차례로 집중 포즈로             |
| 응원 | 함께 일하는 중                       | 가끔 한 캐릭터가 끄덕이거나 통통 뜀(뜀은 최소 2분 간격)            |
| 끊김 | 입력이 잠깐 끊김                     | 포즈 유지, 움직임만 서서히 잦아듦                                  |
| 중단 | 약 45초 입력 없음                    | 기본 포즈로 복귀(타이머 집중 중이면 집중 포즈에서 움직임만 약하게) |
| 재개 | 입력 재개                            | 다시 움직임                                                        |

- 키를 누를 때마다 포즈가 바뀌지 않습니다. 포즈는 필요할 때만 바꾸고, 작업 중에는 **작은 상하 움직임과 기울기**로 노트에 글을 쓰는 듯 반응합니다.
- 마우스를 한 번 움직인 것만으로는 시작하지 않습니다(포인터 이동은 점수가 절반).
- **휴식 타이머 중에는 입력이 있어도 휴식 포즈를 유지**합니다. 입력 활동만으로 타이머를 시작하거나 멈추지 않습니다.
- 설정의 **"내 작업에 반응하기"** 로 켜고 끕니다. 이 환경에서 지원되지 않으면 설정에 사유가 표시되고, 타이머·캐릭터·포스트잇은 그대로 동작합니다.

### 개인정보

- 읽는 값은 운영체제가 주는 **"마지막 입력 후 몇 초"** 하나뿐입니다. 키보드·마우스 후킹(`keyboard`, `pynput` 등)을 쓰지 않으므로, 입력한 글자·키 종류·클립보드·프로그램 이름은 읽을 방법 자체가 없습니다.
- 메모리에는 최근 40초분의 1초 단위 활동 점수만 두고, 디스크에는 쓰지 않습니다.
- 관리자 권한이 필요 없고, 일반 시스템 호출이라 보안 프로그램의 후킹 경고에 걸릴 가능성이 낮습니다.

| OS      | 방식                                     | 비고                                                             |
| ------- | ---------------------------------------- | ---------------------------------------------------------------- |
| Windows | `GetLastInputInfo`                       | 권한 불필요                                                      |
| macOS   | `CGEventSourceSecondsSinceLastEventType` | 권한은 필요 없을 것으로 보이나 **실제 맥에서 확인이 필요합니다** |
| Linux   | X11 XScreenSaver (`libXss`)              | Wayland 세션은 미지원(설정에 표시)                               |

확인: `python chiikawa_desk.py --diagnose-input` 을 실행하고 메모장에 타이핑하면 "마지막 입력 후"가 0 근처로 떨어지는지 볼 수 있습니다.

## 5. 집중 타이머

카드의 버튼으로 조작합니다. 기본 집중 25분, 휴식 5분(설정에서 변경).

| 상황             | 캐릭터 포즈 | 카드 버튼         |
| ---------------- | ----------- | ----------------- |
| 대기             | 기본        | 시작              |
| 집중 중          | 집중        | 일시정지          |
| 집중 일시정지    | 휴식        | 이어하기          |
| 집중 완료        | 응원        | 휴식 시작         |
| 휴식 중·정지     | 휴식        | 일시정지/이어하기 |
| 휴식 완료·초기화 | 기본        | 시작              |

종료 시각을 기준으로 남은 시간을 계산하므로, 앱을 껐다 켜거나 절전에서 돌아와도 이어서 진행됩니다. 남은 시간은 머리 위 쪽지 위의 작은 알약에 표시됩니다.

## 6. 퇴근 시간

설정에서 퇴근 시각(기본 18:00), 요일(기본 월~금), 임박 알림을 정합니다.

- 카드와 알약에 "퇴근까지 1:23"을 표시합니다. 30분 전부터 주황, 10분 전부터 빨강입니다.
- 30분 전·10분 전에 쪽지가 흔들립니다. 정각에는 모든 캐릭터가 응원하고 쪽지에 "퇴근!" 도장이 찍힙니다.
- 퇴근 후에도 작업이 이어지면 "야근" 도장이 찍히고 30분에 한 번 쪽지만 살짝 흔듭니다.
- 트레이의 "오늘은 퇴근 알림 끄기"로 하루만 끌 수 있습니다. 휴식 타이머 중에는 포즈를 바꾸지 않습니다.

## 7. 구조와 시험

```
chiikawa_desk.py   진입점            manager.py      전체 조립(우선순위·타이머·퇴근)
pet.py             캐릭터 창·모션     postit.py       머리 위 포스트잇
panel.py           타이머 카드·설정   notes_store.py  메모 저장(JSON)
idle_probe.py      OS 입력 유휴 시간  work_reactor.py 작업 반응 엔진(Qt 없음)
timer_engine.py    집중/휴식 타이머   clock_out.py    퇴근 계산
prepare_poses.py   12포즈 분리        frames/poses/   잘라 둔 12포즈
```

```bash
python -m unittest discover -s tests     # 로직·화면(offscreen) 시험 27개
```

12포즈 시트 `sprite_sheet_poses.png`는 용량 때문에 저장소에 포함하지 않았습니다. `frames/poses/`를 다시 만들 때만 이 폴더에 넣고 `python prepare_poses.py`를 실행하세요.
(이전 버전의 키보드 치는 모습·랜덤 행동 스프라이트와 `prepare_sprites.py`는 현재 흐름에서 쓰지 않습니다.)

## 8. 확인이 필요한 부분

윈도우·맥의 실제 입력 감지, 투명 창의 클릭 통과, 한글 입력(IME)과 창 포커스는 화면이 없는 환경에서 시험할 수 없었습니다. PC에서 직접 확인해 주세요.
