# 먼작귀 데스크톱 응원 위젯

치이카와·하치와레·우사기가 화면 아래쪽에 함께 서서, **머리 위로 물건(포스트잇·타이머·퇴근 시계)을 들고 다니며** 일할 땐 같이 키보드를 두드리고, 쉴 땐 서로 다른 동작으로 계속 움직입니다.

## 1. 설치와 실행

Python 3.9 이상이 필요합니다. 외부 라이브러리는 PyQt5 하나뿐입니다.

```bash
cd chiikawa-desk
pip install -r requirements.txt
python chiikawa_desk.py
```

- `frames/poses/`(잘라 둔 캐릭터 컷)가 함께 들어 있어 바로 실행됩니다.
- 설정과 메모는 `~/.chiikawa_desk/`(`config.json`, `notes.json`)에 저장됩니다. 내 PC 밖으로 나가지 않습니다.
- 옵션: `--reset`(위치·크기·타이머 초기화, 메모는 유지) · `--debug`(상태 전환 로그) · `--diagnose-input`(작업 감지 확인)

## 2. 조작

| 조작                   | 동작                                                                                                    |
| ---------------------- | ------------------------------------------------------------------------------------------------------- |
| 캐릭터 좌클릭          | 머리 위 물건 펼치기/접기                                                                                |
| 캐릭터 끌기            | **옮기기** (머리 위 물건도 함께). `Shift`+끌기 = 모두 함께 이동                                         |
| 머리 위 쪽지·카드 끌기 | 그 캐릭터가 같이 옮겨짐 (`Shift`+끌기 = 모두)                                                           |
| 마우스 휠 / `Ctrl`+휠  | 그 캐릭터 크기 / **모든 캐릭터** 크기 (0.08~3배, 가장 작게 약 20px)                                     |
| 캐릭터 우클릭          | 펼치기/접기 · 응원 · **머리 위에 올릴 것** · 크기 · 모두 한 줄로 모으기 · 투명도 · 설정 · 숨기기 · 종료 |
| 트레이 아이콘          | 보이기/숨기기 · 모두 한 줄로 모으기 · 설정 · 오늘은 퇴근 알림 끄기 · 종료                               |

캐릭터는 기본 85% 반투명이고 마우스를 올리면 선명해집니다. 말풍선은 없습니다. 글자는 머리 위 물건에만 나옵니다.

## 3. 머리 위에 올릴 것 (설정 가능)

캐릭터마다 머리 위에 올릴 것을 고릅니다. 우클릭 메뉴 또는 설정에서 바꿉니다. 모두 같은 방식으로 **접으면 작은 쪽지, 누르면 펼쳐지고**, 두 손으로 아래 모서리를 잡고 캐릭터의 움직임에 맞춰 흔들립니다.

| 종류            | 접힌 모습          | 펼친 모습                                                          |
| --------------- | ------------------ | ------------------------------------------------------------------ |
| **포스트잇**    | 제목 + 완료/전체   | 폴드 메모 영상의 노트. 제목·본문, `Ctrl+Enter` 체크리스트          |
| **집중 타이머** | 남은 시간(`24:58`) | 시작·일시정지·이어하기 / 초기화 / 응원 / 설정 + 퇴근까지 남은 시간 |
| **퇴근 시계**   | `퇴근 1:23`        | 퇴근 시각·남은 시간, 오늘은 끄기, 설정                             |
| 없음            | —                  | —                                                                  |

기본값은 치이카와·하치와레가 포스트잇, 우사기가 타이머입니다. 집중 타이머와 퇴근 시계는 한 캐릭터만 들 수 있고, 겹치면 앞 캐릭터만 듭니다.

- **포스트잇**: 첫 줄이 제목입니다. `Ctrl+Enter`로 체크 항목을 만들고 항목 앞 ☐ 를 누르면 완료(취소선)가 됩니다. 완료하면 그 캐릭터가 기뻐합니다. 색 점으로 6색을 바꾸고, `×`를 두 번 누르면 내용을 지웁니다. 입력하는 대로 자동 저장됩니다.
- 마감·퇴근 알림은 머리 위 물건이 흔들리고 테두리가 깜빡이는 것으로 알려 줍니다.

> 메모는 PC에 **평문**으로 저장됩니다. 비공개 문서명이나 개인정보는 적지 않는 것을 권합니다.

## 4. 캐릭터의 움직임

### 일할 때: 모두 키보드를 두드립니다

다른 프로그램에서 작업해도(입력 유휴 시간 기반) 캐릭터가 책상에 앉아 함께 키보드를 칩니다. 집중 타이머를 켜지 않아도 동작합니다.

| 단계 | 조건(기본값)                         | 반응                                                    |
| ---- | ------------------------------------ | ------------------------------------------------------- |
| 시작 | 최근 10초 중 활동이 이어짐(3초 이상) | 대표 캐릭터가 **키보드를 두드리기** 시작                |
| 함께 | 약 30초 동안 활동이 이어짐           | 나머지도 1.5~6초 시차를 두고 차례로 키보드를 두드림     |
| 응원 | 함께 일하는 중                       | 가끔 한 캐릭터가 끄덕이거나 통통 뜀(뜀은 최소 2분 간격) |
| 끊김 | 입력이 잠깐 끊김                     | 그대로 유지, 두드리는 강도만 서서히 잦아듦              |
| 중단 | 약 45초 입력 없음                    | 쉬는 동작으로 복귀 (타이머 집중 중이면 노트 집중 포즈)  |
| 재개 | 입력 재개                            | 다시 두드림                                             |

- **서로 같은 동작을 하지 않습니다.** 캐릭터마다 박자(치이카와 보통·하치와레 느긋·우사기 빠름)와 컷 순서, 숨 돌리는 타이밍이 달라서 박자가 맞지 않습니다.
- 키를 누를 때마다 컷이 바뀌는 것이 아니라, 작업량에 따라 일정한 흐름으로 두드립니다.
- 마우스를 한 번 움직인 것만으로는 시작하지 않습니다. **휴식 타이머 중에는 입력이 있어도 휴식 포즈**를 유지하고, 입력만으로 타이머를 시작하거나 멈추지 않습니다.
- 설정의 **"내 작업에 반응하기"** 로 켜고 끕니다. 이 환경에서 지원되지 않으면 사유가 표시되고 나머지 기능은 그대로 동작합니다.

### 쉴 때: 쉬지 않고 서로 다른 동작을 이어갑니다

- 캐릭터마다 동작이 다릅니다. 치이카와(두리번거리기·눈 깜빡임), 하치와레(손 흔들기·고개 갸웃·부끄러움·걱정·깜짝), 우사기(손가락질·두 팔 벌리기·손 흔들기·어지러움·반짝반짝). 공통으로 차 마시기·응원·몸 흔들기·통통 튀기·노트 보기가 있습니다.
- **다른 캐릭터가 지금 하는 동작은 고르지 않고**, 방금 한 동작도 연달아 하지 않습니다. 동작 사이에 숨 돌리는 시간은 1~3초 정도입니다.

### 개인정보

- 읽는 값은 운영체제가 주는 **"마지막 입력 후 몇 초"** 하나뿐입니다. 키보드·마우스 후킹(`keyboard`, `pynput` 등)을 쓰지 않으므로, 입력한 글자·키 종류·클립보드·프로그램 이름은 읽을 방법 자체가 없습니다.
- 메모리에는 최근 40초분의 1초 단위 활동 점수만 두고, 디스크에는 쓰지 않습니다.
- 관리자 권한이 필요 없고, 일반 시스템 호출이라 보안 프로그램의 후킹 경고에 걸릴 가능성이 낮습니다.

| OS      | 방식                                     | 비고                                                             |
| ------- | ---------------------------------------- | ---------------------------------------------------------------- |
| Windows | `GetLastInputInfo`                       | 권한 불필요                                                      |
| macOS   | `CGEventSourceSecondsSinceLastEventType` | 권한은 필요 없을 것으로 보이나 **실제 맥에서 확인이 필요합니다** |
| Linux   | X11 XScreenSaver (`libXss`)              | Wayland 세션은 미지원(설정에 표시)                               |

확인: `python chiikawa_desk.py --diagnose-input` 을 실행하고 메모장에 타이핑하면 "마지막 입력 후"가 0 근처로 떨어지는지 볼 수 있습니다.

## 5. 집중 타이머

머리 위 타이머를 펼쳐서 조작합니다. 기본 집중 25분, 휴식 5분(설정에서 변경).

| 상황             | 캐릭터             | 버튼              |
| ---------------- | ------------------ | ----------------- |
| 대기             | 쉬는 동작          | 시작              |
| 집중 중          | 키보드 / 노트 집중 | 일시정지          |
| 집중 일시정지    | 휴식(차 마시기)    | 이어하기          |
| 집중 완료        | 응원               | 휴식 시작         |
| 휴식 중·정지     | 휴식               | 일시정지/이어하기 |
| 휴식 완료·초기화 | 쉬는 동작          | 시작              |

종료 시각을 기준으로 남은 시간을 계산하므로, 앱을 껐다 켜거나 절전에서 돌아와도 이어서 진행됩니다. 완료·휴식 전환 때 캐릭터들이 같은 순간에 똑같이 바뀌지 않고 조금씩 시차를 둡니다.

## 6. 퇴근 시간

설정에서 퇴근 시각(기본 18:00), 요일(기본 월~금), 임박 알림을 정합니다.

- **퇴근 시계**(또는 타이머 카드)에 "퇴근까지 1:23"을 표시합니다. 30분 전부터 주황, 10분 전부터 빨강입니다.
- 30분 전·10분 전에 머리 위 물건이 흔들립니다. 정각에는 모든 캐릭터가 응원하고 쪽지에 "퇴근!" 도장이 찍힙니다.
- 퇴근 후에도 작업이 이어지면 "야근" 도장이 찍히고 30분에 한 번 살짝 흔들립니다.
- 트레이의 "오늘은 퇴근 알림 끄기"로 하루만 끌 수 있습니다. 휴식 타이머 중에는 포즈를 바꾸지 않습니다.

## 7. 구조와 시험

```
chiikawa_desk.py  진입점              manager.py     전체 조립(모드·타이머·퇴근·머리 위 물건)
pet.py            캐릭터 창·컷·모션    behaviors.py   쉬는 동작·키보드 치기 규칙(Qt 없음)
carried.py        머리 위 물건 공통    postit.py      포스트잇
items.py          타이머·퇴근 시계     panel.py       설정 창
notes_store.py    메모 저장(JSON)      idle_probe.py  OS 입력 유휴 시간
work_reactor.py   작업 반응(Qt 없음)   timer_engine.py / clock_out.py  타이머·퇴근 계산
prepare_poses.py  컷 만들기            frames/poses/  잘라 둔 캐릭터 컷
```

```bash
python -m unittest discover -s tests     # 로직·화면(offscreen) 시험 35개
```

컷 시트(`sprite_sheet_poses.png`, `sprite_sheet_typing.png`, `sprite_sheet_hu.png`)는 용량 때문에 저장소에 포함하지 않았습니다. `frames/poses/`를 다시 만들 때만 이 폴더에 넣고 `python prepare_poses.py`를 실행하세요. (이전 버전용 `prepare_sprites.py`와 `frames/r*.png`는 쉬는 동작 컷 일부(치이카와)에만 쓰입니다.)

## 8. 확인이 필요한 부분

윈도우·맥의 실제 입력 감지, 투명 창의 클릭 통과, 한글 입력(IME)과 창 포커스는 화면이 없는 환경에서 시험할 수 없었습니다. PC에서 직접 확인해 주세요.
