# 치이카와 데스크톱 응원 위젯

바탕화면 위에 투명 배경 치이카와가 떠서, 내가 일하는 모습을 지켜보며 응원해 줍니다.

## 1. 설치 (처음 한 번)

Python 3.9 이상이 필요합니다.

```bash
cd chiikawa-desk
pip install -r requirements.txt
python chiikawa_desk.py
```

- `frames/` 폴더(잘라 둔 프레임)가 함께 들어 있어 바로 실행됩니다.
- `frames/`를 지우면 `sprite_sheet.png`(+ 타이핑 포즈 `sprite_sheet_typing.png`)에서 자동으로 다시 만듭니다(pillow, numpy 필요).

## 2. 사용법

| 조작          | 동작                                                                                                                                                                                  |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 키보드 입력   | 먼저 내가 있는 방향(마우스 커서 쪽)을 잠깐 쳐다본 뒤, 책상에 앉아 **같이 키보드를 침**. 타이핑 속도에 맞춰 계속 움직임(보통 → 열심히 두드림 → 손 멈춤). 4초 멈추면 한숨 돌리고 대기로 |
| 좌클릭        | 깜짝 놀람 / 손 흔들기 / 응원 중 랜덤                                                                                                                                                  |
| 좌클릭 드래그 | 위치 이동 (화면 가장자리 24px 이내면 자동 붙음)                                                                                                                                       |
| 마우스 휠     | 크기 조절 (**0.08 ~ 3배**, 아래 중앙 기준). 가장 작게 하면 약 20px                                                                                                                    |
| 우클릭        | 키보드 치기(미리보기) · 행동 강제 실행 · 크기(초소형~아주 크게) · 투명도 · 설정 · 종료                                                                                                |
| `Ctrl+Alt+C`  | 숨기기 / 다시 보이기 (트레이 아이콘 클릭도 가능)                                                                                                                                      |

- 평소: 눈 깜빡 → 30~60초마다 손 흔들기·삐지기·울먹임·어지러움·하트 중 랜덤
- 5분간 아무 활동이 없으면 낮잠(엎드림), 움직이면 깨어남
- 투명도 기본 85%, 마우스를 올리면 100%
- 설정은 `~/.chiikawa_desk.json`에 저장됩니다. 초기화: `python chiikawa_desk.py --reset`

옵션: `--no-keyboard`(키보드 감지 끔) · `--debug`(상태 전환 로그)

## 3. 키보드 감지 권한

| OS      | 사용 라이브러리               | 필요한 것                                                                                                     |
| ------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Windows | `keyboard` (실패 시 `pynput`) | 보통 없음 (일부 PC는 관리자 권한)                                                                             |
| macOS   | `pynput`                      | **접근성 권한**: 시스템 설정 → 개인정보 보호 및 보안 → 접근성 → 실행하는 터미널(또는 Python)을 허용 후 재실행 |
| Linux   | `pynput`                      | X11 세션 (Wayland는 전역 감지·항상 위가 제한될 수 있음)                                                       |

- 맥에서 `keyboard` 라이브러리는 sudo가 필요해 기본으로 쓰지 않습니다.
- **개인정보**: 어떤 키를 눌렀는지는 읽거나 저장하지 않고 "입력이 있었다"는 사실만 사용합니다.
- **업무 PC**: 보안 프로그램이 전역 키보드 후킹을 막거나 경고할 수 있으니, 설치 전에 정보보안 담당 부서에 확인하세요. 차단되면 `--no-keyboard`로 실행하거나 우클릭 메뉴에서 "키보드 입력 감지"를 끄면 됩니다(마우스 활동 기반 동작은 유지).

## 4. exe / 앱으로 만들기 (선택)

```bash
pip install pyinstaller
pyinstaller --noconsole --onedir --add-data "frames;frames" chiikawa_desk.py   # 윈도우
pyinstaller --windowed  --onedir --add-data "frames:frames" chiikawa_desk.py   # 맥/리눅스
```

## 5. 행(Row) 대응표

1행 정면·깜빡임 / 2행 좌우 보기 / 3행 앞으로 내다보기 / 4행 엎드림(낮잠) / 5행 기쁨 / 6행 손 흔들기 / 7행 당황(땀) / 8행 분노 / 9행 눈물 / 10행 어지러움 / 11행 부끄러움(하트) / **12행 키보드 치기(기본)** / **13행 키보드 치기(열심히·한숨)**

- 12~13행은 두 번째 시트 `sprite_sheet_typing.png`에서 가져오며, 기존 캐릭터와 머리 크기를 맞춰 자동 보정합니다. 말풍선 그림이 박힌 컷(13행 3·4번)은 쓰지 않습니다.
- 1~3행은 7칸, 4~11행은 6칸 격자라서 `prepare_sprites.py`가 행마다 따로 자릅니다. 3행은 엎드린 컷이 칸 경계를 넘어 캐릭터 덩어리 단위로 자릅니다.
