# 먼작귀 데스크톱 응원 위젯

치이카와·하치와레·우사기가 화면 아래쪽에 함께 서서, **머리 위로 물건(포스트잇·퇴근 타이머)을 들고 다니며** 일할 땐 같이 키보드를 두드리고, 쉴 땐 서로 다른 동작으로 계속 움직입니다.

## 1. 설치와 실행

Python 3.9 이상이 필요합니다. 외부 라이브러리는 PyQt5 하나뿐입니다.

```bash
cd chiikawa-desk
pip install -r requirements.txt
python chiikawa_desk.py
```

- `frames/poses/`(잘라 둔 캐릭터 컷)가 함께 들어 있어 바로 실행됩니다.
- 설정과 메모는 `~/.chiikawa_desk/`(`config.json`, `notes.json`)에 저장됩니다. 내 PC 밖으로 나가지 않습니다.
- **PC를 켤 때 자동 실행**이 기본값입니다(현재 사용자의 시작 프로그램에 등록, 관리자 권한 불필요). 설정의 "PC를 켤 때 자동으로 실행"에서 끌 수 있고, 끄면 등록이 지워집니다. 실행 파일(exe)을 옮기면 다음 실행 때 새 경로로 갱신됩니다.
- 옵션: `--reset`(위치·크기 초기화, 메모는 유지) · `--debug`(상태 전환 로그)

## 2. 조작

| 조작                   | 동작                                                                                                    |
| ---------------------- | ------------------------------------------------------------------------------------------------------- |
| 캐릭터 좌클릭          | 머리 위 물건 펼치기/접기                                                                                |
| 캐릭터 끌기            | **옮기기** (머리 위 물건도 함께). `Shift`+끌기 = 모두 함께 이동                                         |
| 머리 위 쪽지·카드 끌기 | 그 캐릭터가 같이 옮겨짐 (`Shift`+끌기 = 모두)                                                           |
| 마우스 휠 / `Ctrl`+휠  | 그 캐릭터 크기 / **모든 캐릭터** 크기 (0.08~3배, 가장 작게 약 20px)                                     |
| 캐릭터 우클릭          | 펼치기/접기 · 응원 · **머리 위에 올릴 것** · 크기 · 모두 한 줄로 모으기 · 투명도 · 설정 · 숨기기 · 종료 |
| 트레이 아이콘          | 보이기/숨기기 · 모두 한 줄로 모으기 · 설정 · 오늘은 퇴근 알림 끄기 · 종료                               |

크기는 **설정 → 캐릭터 크기**에서 슬라이더나 마우스 휠로 조절합니다(0.08~3배). 조절하는 즉시 실제 캐릭터와 창 안 미리보기에 반영되고, 취소를 누르면 원래대로 돌아갑니다.

캐릭터는 기본 85% 반투명이고 마우스를 올리면 선명해집니다. 말풍선은 없습니다. 글자는 머리 위 물건에만 나옵니다.

## 3. 머리 위에 올릴 것 (설정 가능)

캐릭터마다 머리 위에 올릴 것을 고릅니다. 우클릭 메뉴 또는 설정에서 바꿉니다. 모두 같은 방식으로 **접으면 작은 쪽지, 누르면 펼쳐지고**, 두 손으로 아래 모서리를 잡고 있으며 **전혀 움직이지 않습니다**(캐릭터가 숨 쉬듯 움직이거나 동작·컷이 바뀌어도 제자리, 캐릭터를 끌어 옮길 때만 따라옵니다).

| 종류            | 접힌 모습                           | 펼친 모습                                                                                        |
| --------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------ |
| **포스트잇**    | 제목 + 완료/전체가 보이는 알약 막대 | 폴드 메모의 포스트잇: 종이 그라데이션 카드, 머리줄(제목·색·지우기·접기), `Ctrl+Enter` 체크리스트 |
| **퇴근 타이머** | `퇴근 1:23`                         | 퇴근까지 남은 시간, 오늘은 끄기, 설정                                                            |
| 없음            | —                                   | —                                                                                                |

기본값은 치이카와·하치와레가 포스트잇, 우사기가 퇴근 타이머입니다. 퇴근 타이머는 한 캐릭터만 들 수 있고, 다른 캐릭터에게 새로 지정하면 새로 고른 캐릭터가 갖고 먼저 갖고 있던 캐릭터는 포스트잇이 됩니다.

- **포스트잇**(폴드 메모에서 가져온 것): 접힌 알약 막대를 **한 번 누르면 펼쳐지고, 더블클릭하면 이름을 바꿉니다**. 펼치고 접을 때는 280ms 동안 부드럽게 커지고 줄어들며 빛이 훑고 지나갑니다.
  - **제목**은 첫 줄에서 자동으로 만들고(최대 20자), 직접 지으면 그 이름을 유지합니다(비우면 다시 자동).
  - **체크리스트**: `Ctrl+Enter`로 현재 줄을 ☐ → ☑ → ☐ 로 바꾸고, 줄 머리의 ☐ 를 누르면 바로 체크/해제됩니다. `☐`·`□`·`[ ]`·`- [ ]` 같은 표기도 진행률(`1/2`)에 셉니다. 완료하면 캐릭터가 기뻐합니다.
  - **색 8종**: 옐로·샌드·로즈·오렌지·세이지·스카이·라벤더·그래파이트(어두운 종이). 머리줄의 포스트잇 아이콘을 누를 때마다 다음 색, 우클릭 메뉴에서 골라도 됩니다.
  - **여러 장:** 머리줄의 **＋ 버튼**으로 새 포스트잇을 만들고(빈 장으로 열려 바로 쓸 수 있고 색은 장마다 달라집니다), **목록 버튼(☰)**으로 가진 포스트잇을 보고 골라 바꿔 듭니다. 목록 메뉴에서 "이 포스트잇 삭제"도 할 수 있고(내용이 있으면 한 번 더 확인), 하나뿐인 장을 지우면 빈 장이 새로 생깁니다. 캐릭터 한 마리에 30장까지입니다. 이전의 ×(내용 지우기) 버튼은 없어졌고, 내용 지우기는 우클릭 메뉴에 있습니다.
  - **나타날 캐릭터:** 우클릭 메뉴(또는 트레이 메뉴)의 "나타날 캐릭터"에서 원하는 캐릭터만 켜고 끌 수 있습니다(최소 한 마리). 숨겨도 그 캐릭터의 포스트잇은 그대로 보관되고, 다시 나타나면 원래 들던 것을 듭니다.
  - **크기 조절:** 펼친 포스트잇의 **왼쪽 위 모서리(빗금 표시)를 끌면** 크기가 바뀝니다(아래 중앙은 머리에 붙어 있어 위·양옆으로 늘어나고, 최소 180×170 ~ 최대 480×520). 놓으면 저장됩니다. 우클릭 메뉴의 "크기" 프리셋도 그대로 있습니다.
  - **상단 서식 줄**(머리줄 바로 아래): `글꼴 · 제목 · 목록 · B · I · S · 링크`. 기호를 끼워 넣는 방식이 아니라 **글자 자체의 서식**을 바꿉니다. 글자를 선택하고 **오른쪽 클릭 → 「선택한 글자 글꼴…」**에서 글꼴·크기·굵게·기울임을 고르면 **선택한 부분에만** 적용되고(같은 메뉴에 굵게·기울임·취소선·서식 지우기도 있음, 서식 줄의 `글꼴`은 포스트잇 전체 글꼴), B/I/S는 선택한 글자를 굵게·기울임·취소선으로 켜고 끕니다(선택이 없으면 이어서 쓰는 글자에 적용). 제목은 줄 전체를 크고 굵게(1.7·1.4·1.2배), 목록은 줄 머리 글머리·번호·체크, 링크는 주소 글자에 링크 서식을 입히며 `Ctrl`+클릭으로 엽니다. 서식은 글과 함께 자동 저장되어 다시 실행해도 유지되고, 붙여넣기는 글자만 들어옵니다. 저장 버튼은 없고 자동 저장되며, `Ctrl+S`로 바로 저장할 수도 있습니다. 단축키: `Ctrl+B`·`Ctrl+I`·`Ctrl+U`·`Ctrl+K`.
  - 우클릭 메뉴: 이름 바꾸기, 색, **크기**(작게·보통·크게), **글자 크기**, 굵게, 체크 전환, 내용 지우기. `×`는 두 번 눌러야 내용이 지워집니다.
  - 입력하는 대로 자동 저장됩니다("저장됨"). 이전 버전의 메모와 색 이름은 그대로 불러옵니다.
- **퇴근이 임박하면(빨간 글자 시점부터, 색 알림을 꺼 두어도) 모든 캐릭터가 책상·키보드 없이 바퀴 달린 사무용 의자에 앉아 의자에서 천천히 흘러내렸다 올라옵니다**("흘러내려버려~"). 책상은 서서히 사라지고 의자(등받이·앉는 판·기둥·바퀴 받침, 코드로 그린 회색 의자)가 나타나며, **몸은 다리까지 온전히 보이게**(잘리지 않게) 그대로 두고 발끝을 축으로 몸이 내려앉으며 뒤로 살짝 기댑니다(약 2초 내려가 2초 머물고 1초 올라오는 것을 9초마다 반복, 마리마다 시작 시각이 다름). 키를 치지 않는 동안에는 손 모양이 그대로이고, 우클릭 "퇴근 임박 미리보기"로 20초 동안 미리 볼 수 있습니다. 머리 위 물건은 움직이지 않으며, 퇴근 시각이 되면 멈추고 응원합니다.
- 퇴근 알림은 머리 위 물건의 테두리가 천천히 붉게 켜졌다 꺼지는 것으로 알려 줍니다(흔들리지 않음).

> 메모는 PC에 **평문**으로 저장됩니다. 비공개 문서명이나 개인정보는 적지 않는 것을 권합니다.

## 4. 캐릭터의 움직임

캐릭터들은 **내가 키보드를 치는 동안에만** 함께 키보드를 치고, 내가 멈추면 같이 쉽니다. **마우스에는 반응하지 않습니다.** 이를 위해 "키가 눌렸는가"만 확인하고 마지막으로 눌린 시각만 기억합니다(어떤 키인지·입력 내용·마우스 위치·사용 중인 프로그램은 읽거나 저장하지 않고, 후킹도 없습니다).

### 다 같이 키보드를 두드립니다

- 책상에 앉아 **세 캐릭터가 함께 키보드를 두드립니다**(한 번에 약 1~2분 반복). 시작과 끝은 캐릭터마다 조금씩 어긋납니다.
- **서로 같은 동작을 하지 않습니다.** 캐릭터마다 박자(치이카와 보통·하치와레 느긋·우사기 빠름)와 컷 순서, 두드리는 세기, 숨 돌리는 타이밍이 다릅니다. 가끔 한 캐릭터가 고개를 끄덕입니다.
- **내가 일하는 동안에만** 두드립니다. 마지막 키보드 입력 후 3초(설정에서 2~600초)가 지나면 키보드에서 손을 떼고 쉬는 동작만 하며, 다시 입력하면 곧 이어서 두드립니다. **30분 넘게 입력이 없으면 세 마리 모두 차를 마십니다**(설정에서 분 단위로 변경). 설정의 "함께 일하기"에서 끌 수 있고(끄면 계속 두드림), Windows가 아닌 환경에서는 계속 일합니다.
- 키보드를 칠 때는 **세 캐릭터 모두 몸과 책상이 움직이지 않고**, 손 컷만 천천히 바뀝니다.

### 쉴 때는 서로 다른 동작을 계속 이어갑니다

- 일하는 시간 사이의 짧은 쉬는 시간(약 15~40초)에는 캐릭터마다 다른 동작을 합니다. 치이카와(두리번거리기·눈 깜빡임), 하치와레(손 흔들기·고개 갸웃·부끄러움·걱정·깜짝), 우사기(손가락질·두 팔 벌리기·손 흔들기·어지러움·반짝반짝). 공통으로 차 마시기·응원·몸 흔들기·통통 튀기·노트 보기가 있습니다.
- **다른 캐릭터가 지금 하는 동작은 고르지 않고**, 방금 한 동작도 연달아 하지 않습니다. 동작 사이에 숨 돌리는 시간은 1~3초 정도입니다.
- **쉬는 시간에는 키보드를 치지 않습니다.** 일하는 시간이 끝나면 1초 안에 모두 키보드에서 손을 떼고, 쉬는 시간과 내가 일하지 않을 때는 키보드 컷이 한 컷도 나오지 않습니다(시험으로 확인).

### 개인정보

- 키 입력 내용(어떤 키인지), 마우스 위치, 클립보드, 활성 프로그램을 읽는 코드가 없습니다. 후킹도 하지 않으며 쓰는 것은 "키가 눌렸는가" 확인(`activity.py`) 하나뿐입니다(시험으로 확인: 그 밖의 입력 관련 라이브러리·시스템 호출이 있으면 통과하지 못함).
- 저장되는 것은 설정(`config.json`)과 메모(`notes.json`)뿐입니다.

## 5. 퇴근 타이머

설정에서 퇴근 시각(기본 18:00, **키보드로 직접 입력** — `1830`, `18:30`, `18시 30분` 모두 가능), 요일(기본 월~금), 임박 알림을 정합니다.

- **퇴근 타이머**에 "퇴근까지 1:23"을 표시합니다. 30분 전부터 주황, 10분 전부터 **글자가 빨갛게** 바뀝니다(빨강 시점은 설정에서 1~120분 전으로 변경).
- 30분 전·10분 전에 머리 위 물건의 테두리가 천천히 붉게 깜빡입니다. 정각에는 모든 캐릭터가 응원하고 쪽지에 "퇴근!" 도장이 찍힙니다.
- 트레이의 "오늘은 퇴근 알림 끄기"로 하루만 끌 수 있습니다.

## 7. 구조와 시험

```
chiikawa_desk.py  진입점              manager.py     전체 조립(모드·퇴근·머리 위 물건)
pet.py            캐릭터 창·컷·모션    behaviors.py   쉬는 동작·키보드 치기 규칙(Qt 없음)
carried.py        머리 위 물건 공통    postit.py      포스트잇
items.py          퇴근 타이머          panel.py       설정 창
notes_store.py    메모 저장(JSON)      clock_out.py   퇴근 시각 계산
prepare_poses.py  컷 만들기            frames/poses/  잘라 둔 캐릭터 컷
```

```bash
python -m unittest discover -s tests     # 로직·화면(offscreen) 시험
```

컷 시트(`sprite_sheet_poses.png`, `sprite_sheet_typing.png`, `sprite_sheet_hu.png`)는 용량 때문에 저장소에 포함하지 않았습니다. `frames/poses/`를 다시 만들 때만 이 폴더에 넣고 `python prepare_poses.py`를 실행하세요. (이전 버전용 `prepare_sprites.py`와 `frames/r*.png`는 쉬는 동작 컷 일부(치이카와)에만 쓰입니다.)

## 포차코·키티 팩 (선택 · 내 PC에서만)

포차코와 키티는 프로그램에 들어 있지 않고, **내 PC에 만들어 둔 "팩" 폴더에서 불러옵니다**. 그림은 저장소·GitHub 자동 빌드 exe에 한 장도 들어가지 않습니다(`.gitignore`로도 막아 두었습니다).

1. 시트(검은 배경, 6열×12행 스티커 시트)를 PC에 둡니다.
2. 이 폴더에서 `python prepare_pack.py <시트 이미지> --species pochacco`(또는 `--species kitty`) 를 실행합니다(Python + Pillow + numpy 필요). 컷을 잘라(시트의 스티커 테두리·흰 바탕은 지워 윤곽선이 가장자리가 됩니다) `내 PC\.chiikawa_desk\packs\pochacco\`(키티는 `packs\kitty\`)에 만듭니다. 이미 만들어진 팩 폴더를 받았다면 그 폴더를 같은 위치에 넣기만 하면 됩니다. exe 바로 옆 `packs\pochacco`·`packs\kitty` 폴더도 찾습니다.
3. 프로그램을 다시 켜면 **설정 → 나타날 캐릭터**에서 치이카와·하치와레·우사기와 같은 목록으로 **포차코**·**키티**를 체크하고 각각 마리 수(1~4)를 정합니다. 팩이 없으면 그 항목은 꺼진 채 안내 문구만 보입니다. 우클릭 메뉴의 "나타날 캐릭터 → 포차코/키티 마리 수"에서도 바꿀 수 있습니다.
4. **exe 하나로 합치기(배포용):** `build_windows.bat`(빌드 키트의 `build.bat`)가 `packs\pochacco`·`packs\kitty` 폴더가 있으면 exe 안에 함께 넣습니다.

규칙(먹작귀와 같음): 키를 누를 때만 키보드를 치고 0.3초 안에 반응하며, 키보드 컷은 **책상이 같은 한 묶음(7번째 줄)만** 쓰고 책상 위치를 맞춰 책상이 움직이지 않게 합니다(비스듬한 컷·다른 크기의 책상 컷은 쓰지 않음). 쉴 때는 약 24가지 동작을 같은 동작이 겹치거나 연달아 나오지 않게 이어 가고(키티는 5번째 줄이 달라 놀람·떼쓰기 같은 키티만의 동작이 있습니다), 30분 넘게 키 입력이 없으면 차 마시기 컷을 천천히 돌려 봅니다. 여러 마리면 마리마다 박자·동작·크기·머리 위 물건(포스트잇/퇴근 타이머 — 퇴근 타이머는 전체에서 한 마리만)이 따로입니다. 캐릭터가 나올 때만 설정 맨 아래에 저작권 표기(`© 1989, 2026 SANRIO CO., LTD.` 포차코 / `© 1976, 2026 SANRIO CO., LTD.` 키티)가 함께 보입니다(공식 승인 번호는 포함하지 않았습니다).
